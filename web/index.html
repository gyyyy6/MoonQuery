MoonQuery Web Playground

一个用 MoonBit 从零实现的查询引擎：Lexer → Parser → Evaluator，编译成 Wasm/JS 后直接在浏览器里运行。 支持 select <fields|*>、where <field> > <number>、limit <n>；返回的 {"error": ...} 会标红显示。

JSON 数据

一个 JSON 数组，每个元素是一条记录。缺少被过滤字段、或字段不是数字的记录会被静默丢弃。

查询语句

按 Ctrl + Enter（macOS 为 ⌘ + Enter）也可执行。
